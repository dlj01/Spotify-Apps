DEPLOYMENT

  GitHub (Spotify-Apps repo)
  └── http_server_v5/     <- all files (local exe + flask web app)
        ├── app.py              <- Flask entry point (web)
        ├── update.py           <- exe entry point (local)
        ├── spotify.py          <- shared auth + token logic
        ├── top_tracks.py       <- top tracks playlist logic
        ├── recent_tracks.py    <- rewind playlist logic
        ├── requirements.txt
        ├── Procfile
        └── .env.example

  GitHub -> Railway (auto-deploys on every push to main)

  Domain: donnys-spotifyupdater.com
    CNAME -> web-production-d606f.up.railway.app
    TXT   -> Railway domain verification record

______________________________________________________________________

ENVIRONMENT VARIABLES (set in Railway dashboard)

  SPOTIFY_CLIENT_ID      -> Spotify app client ID
  SPOTIFY_CLIENT_SECRET  -> Spotify app client secret
  SPOTIFY_REDIRECT_URI   -> https://donnys-spotifyupdater.com/callback
  FLASK_SECRET_KEY       -> random secret string

______________________________________________________________________

AUTH FLOW

  First run:
    browser -> /login -> Spotify OAuth -> /callback -> tokens.json saved

  Every run after:
    app.py reads tokens.json -> refresh token -> new access token (silent)
